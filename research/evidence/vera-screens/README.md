# Vera app — surviving visual record (saved 2026-10-26)

What's here and where it came from:

- `vera-shot-01..30.png` — the **official Google Play store screenshots** of Vera (288×512 / 249×512 portrait phone shots), recovered from the Wayback Machine snapshot of the Play Store listing taken **23 Feb 2024 — literally the day the app was pulled** (`http://web.archive.org/web/20240223163035/https://play.google.com/store/apps/details?id=us.crema.vera`). Original `play-lh.googleusercontent.com` URLs still resolve directly too (CORS-free CDN); `vera-playpage.html` is the full archived listing page (screenshots embedded + German-localized UI reviews + developer reply).
- `vera-playpage.html` — archived Play listing incl. rating histogram (1,920 reviews; 44% 5-star, 23% 1-star), the June-2020 review reporting **content wiped and then restored by Bloomscape** ("Ihre Pflanzen wurden wiederhergestellt"), and a 2021 German review asking for email-export ("Daten per Mail zuschicken… würde das Wechseln zu einer anderen App enorm erleichtern — klappt auch nicht") — i.e., export was offered as a feature, broken, years before the death.
- Apple side: iTunes lookup API for id 1474870193 now returns 0 results (fully delisted) and no Wayback snapshot of the apps.apple.com page exists — **the App Store screenshots are not recoverable via these routes**.

Video: no Vera-specific demo video found on YouTube (searches hit only Bloomscape general care content; Vimeo blog covers their video program generally). Bloomscape's own live product page remains up as of 2026-10-26: https://bloomscape.com/vera/ (feature copy + testimonial testimonials; Wayback backup 2026-10-08 exists).

Reading tips for the design axis (teardown §5 "tone"): the screenshots are the primary source for how "pet-adoption tone" was executed visually — light, minimal, illustration-led plant profiles. Note the 1-star band (439 reviews) mostly = sync/breakage complaints near the end, per the archived page's recent-sort sample.
